# AMSC InnDaw - Administrative Management & Prospectus System

**AMSC InnDaw** is a web-based administrative management prospectus and institutional system developed for **Adiong Memorial State College (AMSC)**. Built with PHP, MySQL, and modern front-end web technologies, the platform streamlines academic prospectus management, student information tracking, and administrative record handling.

---

## 🌟 Key Features

* **Academic Prospectus Management:** Efficiently manage course curricula, prerequisites, elective tracks, and non-standard unit computations.
* **Student Record System:** Track student profiles, enrollment statuses, and academic progression.
* **Administrative Activity Logging:** Embedded custom audit logging routines to monitor system updates and administrative actions securely.
* **Secure Database Access:** Robust backend integration using prepared statements and try-catch error handling to safeguard institutional data against SQL injection.
* **Responsive Dashboard:** Built with a modern, user-friendly interface tailored for desktop and mobile access.

---

## 🛠️ Tech Stack & Dependencies

* **Language:** PHP
* **Database:** MySQL / MariaDB
* **Front-End:** HTML5, CSS3, JavaScript
* **Development Environment:** XAMPP / Apache
* **Version Control:** Git & GitHub
